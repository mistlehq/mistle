# MCP integration setup keeps secrets and consent user-owned

MCP integration setup tools should prepare sensitive setup steps rather than complete them through agent-visible tool inputs. Secret-bearing setup, provider consent, provider installation, and irreversible provider mutation remain user-owned actions completed through the dashboard/client, while MCP may return structured user-action setup descriptors, create safe pending setup state, perform non-secret direct setup, and continue with post-completion resource, webhook, profile-binding, and trigger setup under explicit permissions. This prevents user-supplied credentials, provider tokens, and consent-bearing actions from entering agent transcripts or MCP tool logs while still letting setup agents guide the integration workflow end to end.
