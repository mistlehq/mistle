# Dashboard control actions may mediate typed product actions

Dashboard control actions are still handled by the active dashboard client, but they may mediate explicitly supported product mutations when the action is typed and the final save is validated server-side against the current Mistle Designer session and target product resources. This narrows ADR 0021's browser-workspace-only boundary: Designer may ask the dashboard to collect structured user input and save it into a Designer-selected draft Sandbox profile version, but the server must validate the target draft, integration connection, binding intent, and selected provider resources before changing saved configuration. The typed action should return the user's submitted answer plus a server-issued receipt describing the resource that changed, so the Designer transcript reflects confirmed product state rather than model intent.
