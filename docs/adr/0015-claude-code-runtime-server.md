# Claude Code uses an SDK-backed runtime server

Mistle supports Claude Code as a first-class **Agent runtime** by running a Mistle-owned Node SDK-backed runtime server inside the sandbox, rather than treating `claude` as a raw PTY-only CLI. The runtime server is adapter code that Mistle builds and modifies; it uses Anthropic's Claude Code Agent SDK as a library to expose Mistle's conversation-provider operations. Mistle does not add a Rust `sandboxd` proxy for Claude Code v1: the Node runtime server owns the semantic translation layer and exposes the final Mistle-facing WebSocket endpoint directly. The Claude Code runtime installs its Node execution dependency through the runtime plan instead of adding Node to every sandbox base image. The first supported credential mode is Anthropic API-key access through Mistle managed egress routes, not Claude subscription login or persisted Claude home auth. Claude Code runs without a Claude-specific interactive tool-approval bridge in this pass because Mistle's sandbox/session isolation and managed egress controls are the v1 security boundary. Claude Code v1 keeps a long-lived SDK session per Mistle conversation so the runtime can support query submission, steering, interruption, and transcript hydration through the existing conversation-provider contract. The Claude Code runtime server exposes Claude-native runtime methods, including `initialize`, `session/create`, `session/resume`, `session/read`, `query/start`, `query/steer`, and `query/interrupt`; the Mistle provider adapter maps generic conversation/execution operations onto those methods. Claude Code may expose a basic terminal launch for interactive inspection when the runtime plan installs a stable `claude` executable, but the Node runtime server remains the supported Mistle conversation path. This keeps trigger delivery, association delivery, transcript ingestion, runtime readiness, steering, interruption, and credential handling on the same product contract as Codex, OpenCode, and Pi without making Claude Code a global sandbox assumption.
