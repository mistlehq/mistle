# Isolate Composer Draft From Runtime Transcript Rendering

The **Composer draft** is local editable UI state and should not be owned by the page-level **Session workbench** component that coordinates the **Active runtime conversation** transcript. Mistle keeps **Composer draft** edits inside the composer-facing UI boundary, isolates transcript rendering from composer-only updates, and leaves provider-specific transcript reconciliation inside each **Agent runtime** adapter while strengthening shared provider-neutral render helpers. We chose this boundary over page-level composer state, a single cross-runtime transcript selector, or immediate transcript virtualization because the observed lag came from unrelated transcript reconciliation during composer typing; virtualization remains a later measured optimization for initial load, scrolling, and memory pressure rather than the first fix for keystroke latency.
