# Mistle Designer uses Langfuse Codex tracing

Mistle Designer will use the Langfuse Codex plugin for Designer-only Codex session tracing, with the plugin installed in the **Mistle Designer base image** and Codex plugin hooks enabled only for **Mistle Designer sessions**. Langfuse credentials are deployment-owned runtime configuration, not organization-owned product configuration; the upstream Langfuse secret key is resolved by Mistle's existing gateway managed direct-egress path and is not injected into Designer sandboxes. When configuration is complete, control plane adds a Designer-only Langfuse managed egress route and injects the upstream Langfuse base URL, public key, a non-secret secret-key placeholder required by the plugin, and Designer session, organization, tag, and environment metadata into the Designer Codex app-server environment. Tracing is enabled for all environments and uses the plugin's documented capture behavior, but observability must not block Designer: incomplete Langfuse configuration is logged server-side and leaves tracing disabled for that session rather than failing session creation.
