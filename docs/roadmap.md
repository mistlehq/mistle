# Roadmap

This roadmap describes areas we are exploring and investing in, not committed release dates.

## Roadmap Areas

- **Mistle CLI:** Enable agents and users to work with Mistle from the command line.
- **Reflection:** Enable sessions to inspect their own state and adjust selected parameters within defined constraints.
- **Triggers:** Make triggers easier to configure, reuse, and debug. This includes templates and examples for common event-driven agent workflows.
- **Self-hosted deployment:** Add clearer deployment paths for specific self-hosting targets, beyond the current local Docker Compose setup.

## Continual Work

- **Coding harnesses:** Improve support for Codex, OpenCode and Pi
- **Integrations:** Expand supported integrations.
- **Sandbox providers:** Expand supported providers.
