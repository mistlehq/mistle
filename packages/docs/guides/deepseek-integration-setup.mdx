## Overview

DeepSeek provides model access for sandbox profiles that use OpenCode-compatible agent runtimes.

Use this connection when a profile should call DeepSeek models through an API key managed by Mistle.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **DeepSeek**, then select **API key**.

Enter:

| Field   | Value            |
| ------- | ---------------- |
| API key | DeepSeek API key |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use DeepSeek.
2. Add DeepSeek as a model provider connection.
3. Save and publish the profile version.
