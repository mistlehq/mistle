## Overview

SigNoz gives Mistle access through a SigNoz OAuth flow and needs the user's SigNoz Cloud region to build the hosted MCP issuer URL.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **SigNoz**, then select **SigNoz OAuth**.

When prompted, enter:

| Field    | Value                                 |
| -------- | ------------------------------------- |
| `region` | SigNoz Cloud region, for example `us` |

Mistle uses that region to build the hosted issuer and MCP URLs:

- Issuer: `https://mcp.<region>.signoz.cloud`
- MCP: `https://mcp.<region>.signoz.cloud/mcp`

After that, the user completes the OAuth redirect flow in SigNoz.

## Official References

- [SigNoz MCP Server](https://signoz.io/docs/signoz-mcp-server/)

The region-specific hosted MCP and OAuth behavior above is inferred from Mistle's current SigNoz integration implementation. SigNoz's public docs currently document the MCP server more directly than this Mistle-specific hosted OAuth flow.
