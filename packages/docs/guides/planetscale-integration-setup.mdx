## Overview

Mistle supports one PlanetScale connection method:

- PlanetScale OAuth

PlanetScale gives Mistle access through a PlanetScale OAuth redirect flow.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **PlanetScale**, then select **PlanetScale OAuth**.

Mistle redirects the browser to PlanetScale, the user approves access, and Mistle stores the returned OAuth credentials for the connection.

There are no user-entered secret fields for this target.

## Official References

- [PlanetScale OAuth](https://planetscale.com/docs/api/reference/oauth)
