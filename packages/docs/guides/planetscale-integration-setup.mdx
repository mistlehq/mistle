## Overview

Connect to PlanetScale through a PlanetScale OAuth redirect flow.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **PlanetScale**, then select **PlanetScale OAuth**.

The browser redirects to PlanetScale, the user approves access, and the returned OAuth credentials are stored for the connection.

There are no user-entered secret fields for this target.

## Official References

- [PlanetScale OAuth](https://planetscale.com/docs/api/reference/oauth)
