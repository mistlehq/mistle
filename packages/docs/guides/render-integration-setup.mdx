## Overview

Connect to Render through Render's hosted MCP server and a Render API key.

The Render MCP server lets agents inspect services, databases, logs, and metrics through the official provider-hosted endpoint.

## Configuring Render Access

Before creating the connection, create or choose a Render API key.

Render API keys can grant broad access across Render workspaces and services. Review the key permissions and only connect keys that are appropriate for agent workflows.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Render**, then select **API key**.

Enter:

| Field   | Value          |
| ------- | -------------- |
| API key | Render API key |
