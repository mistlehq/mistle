## Overview

Connect to Expo through the Expo hosted MCP OAuth redirect flow.

The Expo integration exposes server-side Expo MCP capabilities to agent runtimes, including Expo documentation, compatible package installation guidance, EAS builds, EAS workflows, and TestFlight data.

Local simulator and React Native DevTools capabilities are not enabled by this integration.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Expo**, then select **Expo MCP OAuth**.

The browser redirects to Expo, the user approves access, and the returned OAuth credentials are stored for the connection.

There are no user-entered secret fields for this target.
