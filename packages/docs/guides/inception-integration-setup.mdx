## Overview

Inception Labs provides model access for sandbox profiles that use OpenCode-compatible agent runtimes.

Use this connection when a profile should call Inception Labs models through an API key managed by Mistle.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Inception Labs**, then select **API key**.

Enter:

| Field   | Value                  |
| ------- | ---------------------- |
| API key | Inception Labs API key |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use Inception Labs.
2. Add Inception Labs as a model provider connection.
3. Save and publish the profile version.
