## Overview

Anthropic provides model access for sandbox profiles that use the OpenCode agent runtime.

Use this connection when an OpenCode profile should be able to call Anthropic models through an API key managed by Mistle.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Anthropic**, then select **API key**.

Enter:

| Field   | Value             |
| ------- | ----------------- |
| API key | Anthropic API key |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use Anthropic.
2. In **Runtime**, set **Agent** to **OpenCode**.
3. Add Anthropic as a model provider connection.
4. Save and publish the profile version.

Anthropic connections are only available to OpenCode profiles. Codex profiles use OpenAI-compatible model-provider connections instead.
