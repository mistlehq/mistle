## Overview

Connect to BugSnag through SmartBear's hosted BugSnag MCP server and BugSnag OAuth.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **BugSnag**, then select **BugSnag OAuth**.

The browser redirects to BugSnag, the user approves access, and the returned OAuth credentials are stored for the connection.

There are no user-entered secret fields, project filters, or per-tool restrictions for this target.

## Official Reference

- [SmartBear BugSnag MCP integration](https://developer.smartbear.com/smartbear-mcp/docs/bugsnag-integration)

This integration uses the hosted MCP server at `https://bugsnag.mcp.smartbear.com/mcp`.
