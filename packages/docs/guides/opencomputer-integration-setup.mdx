## Overview

OpenComputer provides a sandbox runtime for running Mistle sandboxes with an organization-owned OpenComputer API key.

Use this connection when a sandbox profile should use workspace-owned OpenComputer credentials.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **OpenComputer**, then select **API key**.

Enter:

| Field   | Value                |
| ------- | -------------------- |
| API key | OpenComputer API key |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should run on OpenComputer.
2. Choose **OpenComputer** as the sandbox runtime.
3. Select the OpenComputer credentials connection.
4. Save and publish the profile version.

For self-hosted deployments, the OpenComputer runtime must also be enabled in deployment configuration before profiles can use it.
