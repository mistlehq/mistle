## Overview

Connect to Cloudflare with a Cloudflare API token.

This integration exposes Cloudflare API MCP Code Mode access to agent runtimes through the Cloudflare MCP server catalog selected on the sandbox profile.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Cloudflare**, then select **API token**.

Enter:

| Field                | Value                                                                   |
| -------------------- | ----------------------------------------------------------------------- |
| Cloudflare API token | Cloudflare API token scoped to the account operations agents should use |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use Cloudflare.
2. Add Cloudflare to the profile's integration configuration.
3. Select the Cloudflare MCP servers the profile should expose.
4. Save and publish the profile version.
