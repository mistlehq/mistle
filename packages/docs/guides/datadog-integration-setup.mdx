## Overview

Connect to Datadog by providing a Datadog API key and application key.

## Configuring Datadog Access

Before creating the connection, make sure:

1. You have a Datadog API key.
2. You have a Datadog application key with the scopes you want to use.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Datadog**, then select **API key + application key**.

Enter:

| Field            | Value                   |
| ---------------- | ----------------------- |
| `apiKey`         | Datadog API key         |
| `applicationKey` | Datadog application key |
