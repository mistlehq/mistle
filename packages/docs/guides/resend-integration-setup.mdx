## Overview

Connect to Resend with a Resend API key.

The Resend integration exposes MCP access for email, contacts, broadcasts, domains, and webhooks.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Resend**, then select **API key**.

Enter:

| Field   | Value                                                                                            |
| ------- | ------------------------------------------------------------------------------------------------ |
| API key | Resend API key. Prefer a sending access key unless agents should manage the wider Resend account |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use Resend.
2. Add Resend to the profile's integration configuration.
3. Select the Resend MCP tool.
4. Save and publish the profile version.
