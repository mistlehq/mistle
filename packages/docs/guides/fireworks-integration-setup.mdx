## Overview

Fireworks AI provides model access for sandbox profiles that use OpenCode-compatible agent runtimes.

Use this connection when a profile should call Fireworks AI models through an API key managed by Mistle.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Fireworks AI**, then select **API key**.

Enter:

| Field   | Value             |
| ------- | ----------------- |
| API key | Fireworks API key |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use Fireworks AI.
2. Add Fireworks AI as a model provider connection.
3. Save and publish the profile version.
