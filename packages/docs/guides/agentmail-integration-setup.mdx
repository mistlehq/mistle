## Overview

Connect to AgentMail through AgentMail's hosted remote MCP server and OAuth flow.

The AgentMail integration exposes inbox, thread, message, draft, and attachment tools to agent runtimes through `https://mcp.agentmail.to/mcp`.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **AgentMail**, then select **AgentMail OAuth**.

The browser redirects to AgentMail, the user signs in, chooses an organization when prompted, and the returned OAuth credentials are stored for the connection.

There are no user-entered secret fields for this target.
