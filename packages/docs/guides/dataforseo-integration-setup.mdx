## Overview

Connect to DataForSEO through DataForSEO's hosted MCP server and DataForSEO OAuth.

The DataForSEO MCP server lets agents access SEO and marketing data from the official DataForSEO APIs, including SERP, keyword, backlinks, on-page, domain analytics, app, merchant, and business data capabilities.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **DataForSEO**, then select **DataForSEO OAuth**.

The browser redirects to DataForSEO, the user approves access, and the returned OAuth credentials are stored for the connection.

## Access Scope

This integration requests DataForSEO's `api` OAuth scope for the hosted MCP server.

Review agent tool calls before approving DataForSEO requests that may create provider-side API costs.
