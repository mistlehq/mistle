## Overview

Tensorlake provides a sandbox runtime for running Mistle sandboxes with an organization-owned Tensorlake API key.

Use this connection when a sandbox profile should use workspace-owned Tensorlake credentials.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Tensorlake**, then select **API key**.

Enter:

| Field   | Value              |
| ------- | ------------------ |
| API key | Tensorlake API key |

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should run on Tensorlake.
2. Choose **Tensorlake** as the sandbox runtime.
3. Select the Tensorlake credentials connection.
4. Save and publish the profile version.

For self-hosted deployments, the Tensorlake runtime must also be enabled in deployment configuration before profiles can use it.
