## Overview

Connect to Stripe through Stripe hosted MCP OAuth.

The Stripe integration exposes hosted MCP access for customers, invoices, products, payments, and documentation.

## Connect In Mistle

Open **Integrations** in the dashboard, choose **Stripe**, then select **Stripe MCP OAuth**.

The browser redirects to Stripe, the user approves access, and the returned OAuth credentials are stored for the connection.

There are no user-entered secret fields for this target.

## Use With A Sandbox Profile

After the connection exists:

1. Open the sandbox profile that should use Stripe.
2. Add Stripe to the profile's integration configuration.
3. Select the Stripe MCP tool.
4. Save and publish the profile version.
