Teams use Mistle to setup sandbox environments for coding agents and manage credentials that the agents use. This allows them to delegate work like improving test coverage, implementing analytics, handling on-call triage, and building well-scoped features.

## Start Here

- Read the product and repository overview in the main project's [README.md](https://github.com/mistlehq/mistle/blob/main/README.md).
- Visit [Docker Compose Quickstart](/guides/self-hosted-docker-compose-quickstart) to get Mistle running locally using Docker Compose.
- Use the provider pages in the `Integrations` section for specific details on how to connect to each provider.
