Mistle is open source software for configuring engineering agents and their execution environments. Teams use it to delegate work like improving test coverage, implementing analytics, handling on-call triage, and building well-scoped features.

## Start Here

- Read the product and repository overview in the main project README.
- Operators should start with [Self-Hosted Configuration](/guides/self-hosted-configuration).
- Users and workspace admins should use the provider pages in the `Connect Integrations` section.
- Use the guides section for deployment and integration setup steps.
