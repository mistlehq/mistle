Mistle is open source software for configuring engineering agents and their execution environments.

This documentation site is for operators and end users:

- operators configuring a deployment
- teams managing integrations and automation
- users connecting tools into sandbox profiles

## Start Here

- Read the product and repository overview in the main project README.
- Operators should start with [Self-Hosted Integrations Overview](/guides/self-hosted-integrations-overview).
- Users and workspace admins should use the provider pages in the `Connect Integrations` section.
- Use the guides section for deployment and integration setup steps.
