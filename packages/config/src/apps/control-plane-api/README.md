# Control Plane API Config Module

Selected service config:

- `control-plane-api`

## Config Keys

| Key                                             | Type                     | Description                                                                   | Default | Env                                                                                              |
| ----------------------------------------------- | ------------------------ | ----------------------------------------------------------------------------- | ------- | ------------------------------------------------------------------------------------------------ |
| `server.host`                                   | `string`                 | Host/interface for the Control Plane API server bind.                         | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_HOST`                                                         |
| `server.port`                                   | `number` (`1..65535`)    | Port for the Control Plane API server bind.                                   | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_PORT` (`Number`)                                              |
| `database.url`                                  | `string`                 | Runtime Postgres connection URL for control-plane API data.                   | None    | `MISTLE_POSTGRES_CONTROL_PLANE_POOLED_URL`                                                       |
| `database.migrationUrl`                         | `string`                 | Direct Postgres connection URL used by control-plane API migration jobs.      | None    | `MISTLE_POSTGRES_CONTROL_PLANE_DIRECT_URL`                                                       |
| `objectStore.bucketName`                        | `string`                 | Bucket name used for control-plane object storage writes and signed reads.    | None    | `MISTLE_OBJECT_STORE_ASSETS_BUCKET_NAME`                                                         |
| `objectStore.region`                            | `string`                 | S3 region used when constructing the bucket-bound object-store client.        | None    | `MISTLE_OBJECT_STORE_ASSETS_REGION`                                                              |
| `objectStore.endpoint`                          | `string`                 | Optional custom S3-compatible endpoint, used for SeaweedFS and local setups.  | None    | `MISTLE_OBJECT_STORE_ASSETS_ENDPOINT`                                                            |
| `objectStore.forcePathStyle`                    | `boolean`                | Optional override for path-style requests to the object-store backend.        | None    | `MISTLE_OBJECT_STORE_ASSETS_FORCE_PATH_STYLE` (`true/false`)                                     |
| `objectStore.accessKeyId`                       | `string`                 | Access key id for the configured S3-compatible object-store backend.          | None    | `MISTLE_OBJECT_STORE_ASSETS_ACCESS_KEY_ID`                                                       |
| `objectStore.secretAccessKey`                   | `string`                 | Secret access key for the configured S3-compatible object-store backend.      | None    | `MISTLE_OBJECT_STORE_ASSETS_SECRET_ACCESS_KEY`                                                   |
| `workflow.databaseUrl`                          | `string`                 | Direct Postgres URL used by OpenWorkflow producer in control-plane.           | None    | `MISTLE_POSTGRES_CONTROL_PLANE_DIRECT_URL`                                                       |
| `workflow.migrationUrl`                         | `string`                 | Direct Postgres connection URL used by control-plane workflow migration jobs. | None    | `MISTLE_POSTGRES_CONTROL_PLANE_DIRECT_URL`                                                       |
| `workflow.namespaceId`                          | `string`                 | OpenWorkflow namespace id used when enqueueing OTP runs.                      | None    | `MISTLE_WORKFLOW_CONTROL_PLANE_NAMESPACE_ID`                                                     |
| `dataPlaneApi.baseUrl`                          | `string`                 | Base URL for data-plane API internal calls.                                   | None    | `MISTLE_SERVICES_DATA_PLANE_API_INTERNAL_URL`                                                    |
| `integrations.activeMasterEncryptionKeyVersion` | `number` (`>=1`)         | Active version for the integrations master encryption key.                    | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_INTEGRATIONS_ACTIVE_MASTER_ENCRYPTION_KEY_VERSION` (`Number`) |
| `integrations.masterEncryptionKeys`             | `Record<string, string>` | Versioned integrations master keyring.                                        | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_INTEGRATIONS_MASTER_ENCRYPTION_KEYS_JSON` (`JSON`)            |
| `dashboard.baseUrl`                             | `string`                 | Public dashboard base URL used for invitation and OAuth redirects.            | None    | `MISTLE_SERVICES_DASHBOARD_PUBLIC_URL`                                                           |
| `auth.baseUrl`                                  | `string`                 | Public base URL used by Better Auth.                                          | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_PUBLIC_URL`                                                   |
| `auth.secret`                                   | `string`                 | Better Auth signing secret.                                                   | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_SECRET`                                                  |
| `auth.trustedOrigins`                           | `string[]`               | Allowed browser origins for auth requests.                                    | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_TRUSTED_ORIGINS` (CSV)                                   |
| `auth.otpLength`                                | `number` (`4..12`)       | OTP code length.                                                              | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_OTP_LENGTH` (`Number`)                                   |
| `auth.otpExpiresInSeconds`                      | `number` (`>=30`)        | OTP expiration window in seconds.                                             | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_OTP_EXPIRES_IN_SECONDS` (`Number`)                       |
| `auth.otpAllowedAttempts`                       | `number` (`1..10`)       | Maximum OTP verification attempts.                                            | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_OTP_ALLOWED_ATTEMPTS` (`Number`)                         |
| `auth.google.clientId`                          | `string`                 | Optional Google OAuth client id. Google login is disabled when omitted.       | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_GOOGLE_CLIENT_ID`                                        |
| `auth.google.clientSecret`                      | `string`                 | Optional Google OAuth client secret. Requires `auth.google.clientId`.         | None    | `MISTLE_SERVICES_CONTROL_PLANE_API_AUTH_GOOGLE_CLIENT_SECRET`                                    |
